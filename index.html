PasswordGame
Offline Password Challenge

Create the Ultimate Password.

PasswordGame is an offline game where your goal is to create a password by following the ever-changing on-screen rules. Each new rule makes the password more challenging, turning a simple task into a fun puzzle.


A web version is also available, while the offline version supports Windows, Linux, macOS, and Android.
