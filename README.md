# **[LinoLV.github.io](https://linolv.github.io)**
A collection of fun, interactive, and creative mini-games built for the web.
Explore the projects below and have fun playing!

---

## 🎮 Projects

### [🪐 Particle Field](https://linolv.github.io/particle-field)
- A game where you match the colored particles to its matching colored rings using attract/repel powers (based on the level)!
- Match all the particles with their corresponding rings to win!

### [🔐 Password Game](https://linolv.github.io/passwordgame)
- A creative puzzle game where your goal is to create a password by following a set of on-screen instructions.
- Offline version: https://github.com/LinoLV/PasswordGame/

### [🎵 Drifting Words](https://linolv.github.io/driftingwords)
- A fun mini game where you can type in (or spawn) many texts into a canvas and it will move, hit the walls, make sound effects when hit to create a music and much more.

### [⏱️ Ten Seconds](https://linolv.github.io/tenseconds)
- Stop the timer at exactly 10 seconds to win.
- Test your timing and precision.
- Simple to play, but harder than it sounds!
